# FortniteTracker Design System

## Pattern

Bento Grid (home) + Feature-Rich Showcase (shop, catalog)

## Style

Vibrant & Block-based + Cyberpunk UI + Glassmorphism

## Colors

- Background: #08080F
- Primary: #00E5FF (neon cyan)
- Accent: #FF2D95 (magenta)
- Surface: rgba(255,255,255,0.06)
- Surface Elevated: rgba(255,255,255,0.1)
- Text: #F0F0F5
- Text Muted: #9898AD

## Typography

- Display: Orbitron
- Body: DM Sans

## Effects

- Gradient mesh backgrounds
- backdrop-blur glass panels
- Glow borders on hover (cyan/magenta)
- Transitions 150-300ms
- prefers-reduced-motion respected

## Anti-patterns

- Generic SaaS blue
- Flat gray cards without depth
- System fonts
- Emoji as icons
